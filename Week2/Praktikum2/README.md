# Praktikum 2 — TextView dan Button

Tombol **Klik Saya!** mengganti isi `TextView` kedua dengan nama contoh dari modul.
Untuk memakai nama sendiri, ubah `name_result` di `app/src/main/res/values/strings.xml`.

Jalankan dari folder proyek.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Lihat [persyaratan build dan lokasi APK](../../README.md).
