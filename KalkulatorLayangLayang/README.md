# Kalkulator Layang-Layang

Ukur diagonal utama dari titik potong ke ujung atas dan ke ujung bawah. Masukkan juga panjang penuh diagonal melintang. Hasil ditampilkan dalam cm² dan cm.

Jalankan dari folder proyek.

```sh
./gradlew assembleDebug
```

APK debug tersedia di `app/build/outputs/apk/debug/app-debug.apk`.
