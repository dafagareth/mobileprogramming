# Praktikum 6 — ListView dengan LinearLayout

Pilih negara pada daftar untuk menampilkan ibu kotanya di bawah daftar.
Data contoh mengikuti modul dan tersimpan di
`app/src/main/res/values/strings.xml`. Urutan pada array `countries`
dan `capitals` harus berpasangan.

Jalankan dari folder proyek.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Lihat [persyaratan build dan lokasi APK](../../README.md).
