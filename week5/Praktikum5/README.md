# Praktikum 5 — ListView dengan Custom Adapter

`MahasiswaAdapter` mengisi `list_item_mahasiswa.xml` dengan NIM, nama,
dan jurusan dari lima contoh mahasiswa dalam modul. Adapter memperbarui
ketiga kolom saat `ListView` memakai ulang sebuah baris.

Jalankan dari folder proyek.

```sh
./gradlew assembleDebug testDebugUnitTest lintDebug
```

Lihat [persyaratan build dan lokasi APK](../../README.md).
